# 팩터 마진 계산기

매입 팩터 / 견적 팩터 기준 마진 자동 계산기. 설치 없이 HTML 파일을 브라우저로 열면 동작합니다.

| 파일 | 용도 |
|---|---|
| `pc.html` | PC용. 마진 계산 · 팩터 역산 · 조견표를 한 화면에 표시 |
| `mobile.html` | 모바일용. 큰 입력칸, 탭 전환(마진 / 역산 / 조견표) |

## 계산식

- 마진율(매출이익률) = 1 − 매입F ÷ 견적F
- Markup(매입가 대비 인상률) = 견적F ÷ 매입F − 1
- 필요 견적F = 매입F ÷ (1 − 목표마진)
- 금액 = 리스트가 × 팩터 (리스트가 입력 시)

예) 매입F 0.48, 견적F 0.60 → 0.48 ÷ 0.60 = 0.80 → 마진 20%, Markup 25%

## 참고

- 역산 결과는 소수 3자리 **올림** 값을 같이 표시합니다. 반올림하면 목표 마진보다 낮아질 수 있기 때문입니다.
- 매입가에 N%를 올리는 방식(Markup)은 마진 N%가 아닙니다. 예) 20% 인상 → 마진 16.7%
- 입력값은 해당 브라우저 localStorage에만 저장되며 외부로 전송되지 않습니다.
